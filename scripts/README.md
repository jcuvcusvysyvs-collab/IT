# Синхронизация общей раскладки

Сайт — набор HTML-страниц. Футер, меню и версии общих CSS/JS живут в одном месте и копируются на все страницы командой.

## Одна команда

Из корня проекта:

```bash
python scripts/sync-all.py
```

Проверка без записи (если страницы «разъехались» — код выхода 1):

```bash
python scripts/sync-all.py --check
```

Старые скрипты `sync-site-footer.py` и `sync-site-header.py` тоже вызывают `sync-all.py`.

## Что где править

| Что меняете | Где |
|-------------|-----|
| Ссылки и текст футера | `_partials/footer-home.html` (главная), `_partials/footer-subpage.html` (остальные) |
| Пункты меню «Услуги / Проекты / О компании» | списки `SERVICE_LINKS` / `PROJECT_LINKS` / `ABOUT_LINKS` в `scripts/sync-all.py` |
| Версии кэша `styles.css`, `nav.js`, темы, футер-скриптов | `scripts/site-assets.json` |

После правки всегда запускайте `python scripts/sync-all.py`.

## Что не синхронизируется

- Контент страниц (тексты, кейсы, формы)
- Страничные стили: `contacts.css`, `about.css`, `projects.css` и т.п. — их `?v=` меняйте на самой странице
- `404.html` и `client-projects.html` без стандартного футера/меню обрабатываются частично или пропускаются

## Зачем это нужно

Одна правка футера или версии CSS применяется ко всем страницам одинаково — без ручного обхода ~80 HTML-файлов.
